## Sobre

Sou desenvolvedor há **6 anos**. Comecei desmontando coisas que já funcionavam para
entender por quê, e sigo com a mesma curiosidade — só que agora construindo do zero.

Trabalho principalmente com **React** e **Next.js**, mas o que me interessa de verdade é a
parte que o usuário sente: o tempo de resposta, o que acontece quando algo dá errado, o
detalhe que ninguém nota até faltar.

- 🛠️ Front-end com TypeScript, React e Next.js — e React Native no mobile
- 🗄️ Back-end com Node.js, APIs REST, Supabase e bancos relacionais
- 🖥️ Também escrevo C#, C++ e Python quando o problema pede
